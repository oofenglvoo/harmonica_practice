# 音阶练习 · 听见每一个音

一个纯前端的音阶听辨与视唱练习工具，帮助学习者建立数字、唱名和音高之间的连接。无需安装、无需构建，浏览器打开即用。

## 功能

### 音阶播放器
- **播放/暂停/重开/静音**：一键控制整条音阶的播放。
- **方向选择**：上行、下行、上下行（Do→Si→Do）。
- **顺序/随机**：顺序跟唱，或随机打乱顺序进行听辨。
- **速度调节**：滑块控制每个音的间隔（500–1800ms），分为快/中/慢三档。
- **12 个大调**：C、Db、D、Eb、E、F、Gb、G、Ab、A、Bb、B 大调任意切换。
- **7 种音色**：钢琴、木琴、长笛、吉他、口风琴、口琴、纯音，全部由 Web Audio API 实时合成，无任何音频文件。
- **键盘快捷键**：按键 `1`–`7` 可直接播放对应音符。

### 听音挑战
- 播放一个随机音，从 7 个唱名按钮中选择你认为正确的答案。
- 答对/答错即时反馈，并统计本轮正确率。

### 界面
- 大字号音符展示（数字 + 唱名 + 音名 + 频率），进度条与练习计时。
- 响应式布局，桌面与移动端均可使用；建议佩戴耳机练习。

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript，无框架、无依赖、无构建步骤。
- 声音由 Web Audio API 振荡器合成（钢琴音色含多泛音与低通滤波，口琴音色含颤音）。
- 字体：Manrope、DM Mono（Google Fonts）。

## 使用方法

1. 克隆或下载本仓库：
   ```bash
   git clone https://github.com/oofenglvoo/harmonica_practice.git
   ```
2. 直接用浏览器打开 `index.html` 即可（部分浏览器要求本地文件通过 `http://` 访问音频，如遇问题可运行任意静态服务器，例如 `python -m http.server`）。
